# Install OpenMotion

For a new installation, follow the [source installation guide](../install.md). Install OpenMotion from the repository; do not resolve or execute a published application package.

## Installation-success reply

Source installation and plugin setup share the [installation onboarding contract](install-onboarding.md#installation-success-reply).

The old npm guide template is retained in [legacy release tooling](templates/npm-install.md) for historical artifact verification, not as a new installation entry. Existing installations and their projects are preserved.
